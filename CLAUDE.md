# Project Instructions

This repository is a learning environment focused on:

- Claude Code
- Terraform
- AWS
- Infrastructure as Code
- Cloud Security

## Rules

- Never execute `terraform apply`.
- Never create real cloud resources.
- Never expose credentials or secrets.
- Prefer least privilege.
- Explain findings before recommending changes.
- Do not modify Terraform files unless explicitly requested.
- Do not invent infrastructure context.
- Clearly separate security vulnerabilities from hardening recommendations.
